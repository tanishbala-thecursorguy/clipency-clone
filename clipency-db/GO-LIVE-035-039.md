## Approved changes to existing things (owner, 2026-10-22)

1. **24-hour review limit** (`035`): the `campaigns.client_review_hours` default goes from 48 to 24 and its allowed range from 1–168 to 1–24. All 13 campaigns are at 48 today and get set to 24. The 7 clips waiting for review right now **keep their current deadlines**; only new clips get 24h.
2. **Rejections need 15+ characters** (`035`): the live `client_review_clip` function is replaced by a copy with only that one rule changed (checked against the live version).
3. **Appeal approvals** (`037`): "Approve clip" in an appeal turns that one rejected clip into approved, the same as an approval from the review queue.
4. **Realtime + storage** (`039`): the new chat tables join Supabase Realtime, plus a new `appeal-attachments` bucket and a rule for uploads into it.
5. **New scheduled jobs** (`039`): 3 new jobs. The 8 existing jobs are untouched.
